# Welcome!

The **Extracorporeal Life Support Common Data Model (ECLS CDM)** is a
**community-driven expansion** for the **Observational Medical Outcomes
Partnership Common Data Model (OMOP CDM)**.

**To quote our work:**

> Rieder C, Zhuk A, Said A, Becker-Pennrich AS, Dietz K, Bělohlávek J, Geppert J, Horvat C, Barbaro RP, Tonna JE, Conrad SA, Broman LM, Reich C, Blacketer C, Brodie D, Alexander PMA, Hoechter DJ. Expanding the OMOP common data model to support extracorporeal life support research. JAMIA Open. 2026 Jun 22;9(3):ooag112. doi: 10.1093/jamiaopen/ooag112. PMID: 42339164; PMCID: PMC13284988.

Find out more about the project reading the official [documentation](https://ecls-cdm.github.io/cdm/)!
Feel free to ask questions using the [discussions](https://github.com/ecls-cdm/cdm/discussions).
